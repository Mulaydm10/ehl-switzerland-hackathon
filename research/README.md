# Research

This directory tracks two append-only logs:

- **`prior_art.md`** — existing products/projects/papers relevant to whatever idea gets chosen. Check
  this before committing build time to an idea; a hackathon project that duplicates an existing
  product wastes the one resource that can't be recovered (time).
- **`open_questions.md`** — every open question under a stable ID, **`Q-####`**. This is where the
  three founding unknowns of this repo live: event identity (Q-0001), thesis (Q-0002), and stack
  (Q-0003). Resolving a `Q-####` means updating the relevant LOCKED file (via Dhruv, logged in
  `GOVERNANCE.md`) and marking the question closed here — never deleting the row.

Both files are append-only (see `GOVERNANCE.md`): add rows, don't rewrite them. This README
describing the process is what's LOCKED; the two log files are append-only data.
