# Glossary

Prevents naming drift across sessions and agents. Add a term the moment you notice two people/agents
using different words for the same thing, or the same word for different things.

| Term | Meaning in this repo |
|---|---|
| Main Agent | Dhruv — sole authority over LOCKED files. See `GOVERNANCE.md`. |
| LOCKED | A file that opens with the LOCKED banner and may only be edited by the Main Agent (or with sign-off), with every edit logged in `GOVERNANCE.md`. |
| Claim | A row in `STATE.md`'s work-claims table reserving a top-level directory for one agent/person; released the moment work stops. |
| Lane | Agent-bus terminology for a top-level directory as the unit of ownership — relevant only if/when this repo is grafted onto the agent-bus protocol. See `AGENTS.md`. |
| `ADR-####` | An architecture/process decision record, in `design/decisions/`. |
| `Q-####` | An open question, in `research/open_questions.md`. |
| `EXP-####` | An experiment or spike, in `experiments/experiment_log.md`. |
| `DEMO-####` | A judge-facing demo scenario, in `DEMO.md`. |
| `TODO(Dhruv)` | A deliberate placeholder for a fact not yet known — never fill it with an invented value. |
