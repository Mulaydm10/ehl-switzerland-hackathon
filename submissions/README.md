# Submissions

Staging area for the actual deliverables named in `COMPETITION.md`'s submission-format section
(currently `TODO(Dhruv)` — format unknown until the event is confirmed, see Q-0001).

Once the submission format is known, this directory should hold exactly what needs to be handed in
(e.g. a final write-up, a demo video, a packaged build, a link sheet) — not working files. Working
files stay in whatever top-level directory owns them; only the finished, submission-ready artifact
lands here.

Do not assume a format (repo link vs. zipped build vs. slide deck vs. deployed URL) until
`COMPETITION.md` says so explicitly.
